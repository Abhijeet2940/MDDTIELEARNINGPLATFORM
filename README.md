# MDDTI Sealdah React App

This project recreates the Multi-Disciplinary Divisional Training Institute website as a componentized React application using React Router and a responsive design system.

## Included sections

- Home landing page with trainee access cards
- About Us overview
- Faculty listing
- Contact page with embedded map and demo form
- Responsive header and footer navigation

## Run locally

```bash
npm install
npm start
```

The app runs in development mode at http://localhost:3000.

## Build for production

```bash
npm run build
```

## Notes

- The project uses JavaScript and Create React App.
- External portal links such as TRMS and LMS are left as live links to the original destination.
- The contact form is a frontend demo and does not submit to a server yet.
